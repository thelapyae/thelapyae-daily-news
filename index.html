SpeedCrunch ၏ တရားဝင်စာမျက်နှာ ဖြစ်ပြီး ဗားရှင်း 1.1 ကို ဖော်ပြသည်။ Open-source high-precision scientific calculator ဖြစ်ပြီး Windows၊ macOS နှင့် Linux တွင် အခမဲ့ရနိုင်သည်။ Precision 50 digit အထိ၊ complex number၊ function ၁၄၀ ကျော်၊ unit နှင့် constant များ၊ vector နှင့် matrix ပံ့ပိုးမှုတို့ ပါဝင်သည်။ User-defined variable နှင့် function များလည်း သတ်မှတ်နိုင်သည်။

အဓိကအချက်များ

  • Scientific calculation အတွက် precision ကို 50 digit အထိ ထိန်းသည်။
  • Matrix၊ unit နှင့် custom function များကို တစ်ခုတည်းတွင် စီမံနိုင်သည်။
